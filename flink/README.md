# Apache Flink Fraud Processing - Member 2

This is the Flink counterpart of the Member 2 Spark processing layer.

It contains:
- IEEE-CIS historical batch preparation
- Kafka real-time streaming
- Event-time timestamps and watermarks
- Keyed/windowed feature aggregation
- Basic keyed-state descriptors
- Tests and benchmark scaffolding

Recommended environment: Python 3.11, PyFlink 2.3.0, Java 17.
