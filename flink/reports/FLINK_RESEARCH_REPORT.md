# Flink Research Report - Member 2

## Research question
How can Apache Flink provide a unified processing layer for large-scale historical fraud analysis and real-time transaction stream processing?

## Contribution
This module prepares IEEE-CIS historical data and demonstrates real-time transaction processing with event time, watermarks, keyed streams, and sliding windows.

## Metrics to measure
- batch processing time
- streaming throughput
- end-to-end latency
- late-event handling
- CPU/memory usage
- checkpoint behavior

Spark and Flink results should be measured experimentally rather than assigned assumed winners.
